## 📖 О проекте

**«Оператор СОКОЛ»** — это серия бесплатных образовательных 3D-тренажёров для обучения управлению беспилотными летательными аппаратами. Проект создан в рамках инициативы **Anti-AI Shield** и распространяется полностью бесплатно.

**Урок 4: Высотный полёт** — задание на высотное пилотирование и точное пикирование. Оператор управляет дроном на большой высоте, пикирует сверху на наземные цели, попадает в узкую зону захвата и возвращается на высоту.

> 💙 Проект был и останется бесплатным.

---

## 🎯 Особенности

- 🌐 **Полностью офлайн** — работает без интернета после загрузки
- 🎮 **3 уровня сложности**: Лёгкий, Средний, Сложный
- 🎯 **Система захвата целей** — нужно удерживать цель в конусе поражения
- 🌡️ **Режим тепловизора** — переключение по клавише `T`
- 🎵 **Процедурный звук** — генерируется через Web Audio API
- 💥 **Реалистичные столкновения** — с порогом крушения, зависящим от сложности
- 📱 **Адаптивный дизайн** — работает на ПК и планшетах
- ⚡ **Оптимизация** — авторежим для слабых устройств (`isLowEnd`)
- 🎨 **Красивый UI** — градиенты, анимации, неоновое свечение

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `W` / `↑` / `Ц` | Движение вперёд |
| `S` / `↓` / `Ы` | Движение назад |
| `A` / `←` / `Ф` | Влево |
| `D` / `→` / `В` | Вправо |
| `Q` / `Shift` | Набор высоты |
| `E` / `Ctrl` | Снижение / Пикирование |
| `ЛКМ` (удерживать) | Точное наведение / захват цели |
| `T` | Переключение режима (обычный / тепловизор) |

## 📊 Уровни сложности

| Параметр | 🟢 Лёгкий | 🟡 Средний | 🔴 Сложный |
|----------|-----------|------------|------------|
| Время | 4 мин | 3 мин | 2 мин |
| Целей | 3 | 5 | 7 |
| Зона захвата | Широкая (4м) | Средняя (3м) | Узкая (2м) |
| Время удержания | 1.2 с | 1.5 с | 1.8 с |
| Порог крушения | 0.25 | 0.18 | 0.12 |

## 🛠️ Технологии

- **Three.js r128** — 3D-рендеринг
- **Web Audio API** — процедурные звуки
- **HTML5 + CSS3** — интерфейс с градиентами и анимациями
- **Vanilla JavaScript** — без фреймворков и сборщиков
